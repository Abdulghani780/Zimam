# سير عمل البناء والتجهيز للإنتاج (Release & Build Workflow)
# المسار: .agent/workflows/release_and_build.md
# ==============================================================================

## الهدف
التحقق النهائي من جاهزية النظام، بناء كافة الأصول البرمجية، ومزامنة `dist/` مع كود الواجهة.

---

## 🚀 قائمة فحص الإصدار والبناء (Release Checklist)

### 1. تدقيق التناسق البرمجي
- [ ] خلو مشروع الفرونت إند من أخطاء الـ TypeCheck:
  ```powershell
  cd frontend && npx tsc --noEmit
  ```
- [ ] خلو مشروع الباك إند من أي استيرادات غير معرّفة أو تسريبات ذاكرة:
  ```powershell
  python -m unittest discover tests
  ```

### 2. توليد حزمة الإنتاج وتحديث dist/ (Mandatory Production Build)
- [ ] **بناء الواجهة ونقلها لمجلد `dist/`:**
  ```powershell
  npm --prefix frontend run build
  ```
- [ ] **التحقق من ملفات التوزيع في الجذر:**
  - وجود `dist/index.html` بتحديث زمني حديث.
  - وجود مجلد `dist/assets/` محتوياً على ملفات JS و CSS والخطوط والأيقونات.
- [ ] التأكد من أن `backend/app/core/config.py` يقرأ المسار الصحيح للملفات (`dist/`).

### 3. الفحص التشغيلي في المتصفح
- [ ] التحقق من استجابة خادم الويب على المنفذ `8765` أو تشغيله:
  ```powershell
  python -m backend.app.main
  ```
- [ ] فتح المتصفح على `http://127.0.0.1:8765/` والتأكد من:
  1. تحميل الواجهة المحدثة فوراً.
  2. ظهور الروابط الجديدة في القائمة الجانبية (Sidebar).
  3. عمل كافة المسارات والأزرار بدون أخطاء في الـ Console.
