# سير عمل تطوير واجهات الفرونت إند (Frontend Development Workflow)
# المسار: .agent/workflows/frontend_development.md
# ==============================================================================

## الهدف
دليل هندسي إلزامي لأي عملية تطوير، تعديل، أو إضافة صفحات ومكونات في الواجهة الأمامية لنظام `ASAAS-Server-Control-v2`.

---

## ⚠️ الشروط الإجبارية غير القابلة للتجاوز (Mandatory Gates)

### 1. تسجيل الصفحات الجديدة (Route & Sidebar Registration)
عند إنشاء أي صفحة جديدة في `frontend/src/pages/YourPage.tsx`:
- [ ] **خطوة 1 - إضافة المسار في `App.tsx`:**
  - استيراد الصفحة في `frontend/src/App.tsx`.
  - إضافة مسار الـ `<Route path="your-route" element={<YourPage />} />` داخل المخطط العام `<Layout />`.
- [ ] **خطوة 2 - إضافة الزر في `Sidebar.tsx`:**
  - اختيار أيقونة مناسبة من `lucide-react`.
  - إضافة عنصر `<NavLink to="/your-route" ...>` داخل القسم المناسب في `frontend/src/components/Sidebar.tsx`.
  - التحقق من دعم اسم الصفحة باللغة العربية وتوافق الألوان.

---

### 2. البناء الإلزامي وتحديث مجلد التوزيع (Mandatory Dist Build)
- [ ] **خطوة 3 - تنفيذ أمر البناء فوراً:**
  السيرفر الرئيسي للباك إند يعرض الملفات من مجلد `dist/` المجمع. أي تعديل في `frontend/src/` **لن يظهر في المتصفح** ما لم يتم البناء!
  قم بتشغيل الأمر التالي في الطرفية:
  ```powershell
  npm --prefix frontend run build
  ```
  أو:
  ```powershell
  cd frontend && npm run build
  ```
- [ ] **خطوة 4 - التحقق من سلامة البناء:**
  - التأكد من انتهاء الأمر بنجاح كود 0 وخلوه من أي أخطاء TypeScript أو Vite.
  - التحقق من تحديث الملفات داخل مجلد `dist/` (`dist/index.html` و `dist/assets/`).
- [ ] **خطوة 5 - التحقق من الخادم الحي:**
  - فتح أو فحص الخادم على المنفذ `http://127.0.0.1:8765/` للتأكد من ظهور الصفحة أو التعديل الجديد فوراً.

## 🎨 معايير الواجهات الفخمة (Luxury UI Checklist)
- [ ] استخدام المتغيرات الدلالية للنظام (`var(--accent)`, `var(--bg-1)`, `var(--text-1)` إلخ).
- [ ] منع استخدام ألوان Hex ثابتة داكنة hardcoded داخل المكونات لتفادي تشوه الوضع الفاتح (Light Mode).
- [ ] دعم اتجاه RTL العربي والتناسق مع خطوط ثمانية (Thmanyah).
- [ ] ربط كافة الأزرار بوظائف حقيقية، حوارات تأكيد، أو إشعارات Toast حية (Zero Fake Buttons).
