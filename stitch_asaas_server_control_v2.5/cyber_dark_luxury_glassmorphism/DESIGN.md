## Brand & Style

This design system establishes a high-density, mission-critical operational aesthetic tailored for enterprise server administration, zero-trust perimeter control, and infrastructure orchestration. Blending the computational precision of top-tier Unix telemetry consoles (NOC/SOC) with royal, heritage-grade Arabian luxury, the visual character asserts sovereign confidence, high performance, and absolute technical authority.

### Target Audience & Psychological Intent
Crafted for senior infrastructure architects, DevOps governors, and cybersecurity engineers who monitor mission-critical systems under high pressure. The interface evokes unyielding stability, prestige, and swift situational awareness: deep void backgrounds prevent visual fatigue during prolonged shifts, while gleaming metallic accents and precise telemetry glows elevate administrative work to an executive-level command experience.

### Design Movement: Cyber Dark Luxury Glassmorphism
The visual architecture merges three contemporary paradigms:
- **Cyber Dark Glassmorphism:** Smoked obsidian planes floating over carbon-black canvases with heavy 24px backdrop diffusion, illuminated at the seams by hairline metallic filaments.
- **Sovereign Luxury Minimalism:** Restrained, intentional deployment of heritage golds, warm sandstone typography, and deep charcoal finishes in place of generic fluorescent tech palettes.
- **RTL-First Precision Engineering:** Deep bidirectional consideration where high-register Arabic typography drives navigation, analytical labels, and situational alerts, while LTR technical telemetry (IPv6, SHA-256 hashes, Unix ports, CLI parameters) is nested cleanly without directional dissonance.

## Colors

The chromatic structure operates on strict functional segregation between structural housing, sovereign accents, and diagnostic telemetry.

### Surfaces & Foundations
The canvas is anchored in deep carbon `#0c0c0e`, eliminating ambient glare and light bleed. Container tiers employ smoked glass `rgba(22, 20, 20, 0.72)` supported by a structural hairline boundary (`rgba(212, 160, 23, 0.18)`). Secondary sub-surfaces (`#141111`) ground stacked elements without breaking tonal unity.

### Sovereign Metallics
The interactive identity relies on an authentic royal gold spectrum:
- **Primary Gold (`#d4a017`):** Directs primary interactive intent, focus perimeters, and active navigational pivots.
- **Luminescent Accent (`#ffd700`):** Reserved for urgent security status elevations, AI governor pings, and elevated clearance tokens.
- **Radiant Glow (`#f0be38`):** Ambient illumination for interactive states and AI telemetry triggers.
- **Warm Bronze (`#ba9555`):** Structural borders and secondary badges.

### Text Luminance Hierarchy
To ensure effortless parsing across dense tabular and graphical layouts:
- **Title Luminance (`#fcfaf7`):** Warm pearl white for dominant headings and large real-time KPI metrics.
- **Body Sandstone (`#d6d0c4`):** Soft parchment tone providing high readability without optical vibration against dark surfaces.
- **Bronze Metadata (`#8a8478`):** Muted contrast for units of measurement (ms, GB, %), table headers, and timestamp audit trails.

### System Telemetry & Diagnostic Spectrum
Operational health signals use standardized, hyper-vibrant signal colors set against subdued 12–14% translucent surface pods:
- Safe / Connected: `#22c55e` (Emerald)
- Warning / Idle: `#f59e0b` (Amber)
- Danger / Intrusion: `#ef4444` (Crimson)
- System / Protocols: `#38bdf8` (Sky)

For GNOME-style multi-core CPU monitoring, an 8-channel dedicated spectrum (`core-01` through `core-08`) provides distinct, non-colliding Bezier line traces across real-time oscilloscope visualizers.

## Typography

The typographical engine bridges classical literary prestige with rigorous machine telemetry.

### Font Role Separation
- **Display & Headings (Noto Serif):** Serves as the authoritative, classical editorial voice across Arabized headers, system metric counters, and executive module crowns.
- **Interface Body (IBM Plex Sans):** Provides neutral, highly legible sans-serif clarity across dense operational tables, navigation panels, form inputs, and descriptive alerts.
- **Technical Telemetry (JetBrains Mono):** Enforces strict tabular alignment for IPv4/IPv6 addresses, port identifiers, CLI flags, memory addresses, and cryptographic hashes.

### Directional Rule & LTR Isolation
While the host interface executes in native `dir="rtl"`, all technical telemetry, network addresses, script fragments, and masked hash credentials must reside within strict LTR inline boundaries (`dir="ltr"`, `unicode-bidi: isolate`). This prevents punctuation drift, flipped CIDR notation, and malformed command line scripts.

## Layout & Spacing

The structural layout adheres to an operational command center architecture with a fixed right-side anchor and fluid internal telemetry panes.

### Master Geometry
- **RTL Fixed Sidebar:** Anchored strictly to the right boundary with a permanent width of `260px` on desktop viewports.
- **Operational Glass Header:** Fixed `60px` height spanning the content canvas, housing live Server-Sent Events (SSE) telemetry, emergency action triggers, and active authority badges.
- **Global Canvas Limits:** Maximum application boundary constrained to `1600px` with `--page-pad` standard margins.

### Multi-Device Reflow
- **Desktop (1080px+):** Full 12-column telemetry grid; the 8-core CPU oscilloscope renders alongside the 4-column diagnostic legend; tables display all security auditing fields without truncation.
- **Tablet (641px – 1079px):** Oscilloscope legend wraps from 4 columns to 2 columns; top KPI metrics reflow to a 2x2 grid; sidebar collapses to an off-canvas drawer accessed via the glass header.
- **Phone (≤ 640px):** Layout becomes a single vertical stack; complex tables reflow into discrete card capsules; touch targets maintain a minimum dimension of `44px` (`--tap`).

## Elevation & Depth

Visual hierarchy is constructed entirely through tonal transparency and ambient photonic occlusion rather than traditional drop shadows.

### Smoked Glass & Blur Atmosphere
Every container floats as an illuminated dark lens. Surfaces use `backdrop-filter: blur(24px)` over `rgba(22, 20, 20, 0.72)`. This permits hints of ambient background activity (such as moving network waveforms and system pulses) to register subtly beneath structural cards without compromising contrast or data legibility.

### Hairline Gold Containment
Instead of heavy borders, visual boundaries are defined by a crisp 1px perimeter using `rgba(212, 160, 23, 0.18)`. When a module gains focus or elevated authority, this perimeter transitions to an active gold glow using `box-shadow: 0 0 16px rgba(240, 190, 56, 0.35)`.

### Tiers of Elevation
- **Tier 0 (Canvas):** Pure `#0c0c0e` carbon background. Zero blur, zero shadow.
- **Tier 1 (Panels & Cards):** Smoked glass `rgba(22, 20, 20, 0.72)` + 1px gold hairline boundary + diffused deep shadow `box-shadow: 0 12px 32px rgba(0, 0, 0, 0.65)`.
- **Tier 2 (Floating Governors & Modals):** Smoked glass with enhanced opacity `rgba(18, 16, 16, 0.92)` + 1px high-tone gold rim (`#d4a017`) + ambient aura `box-shadow: 0 20px 48px rgba(0, 0, 0, 0.85)`.
- **Tier 3 (AI Assistant Bubble):** Floating sphere hovering with a multi-layered gold pulse `box-shadow: 0 0 24px rgba(240, 190, 56, 0.4)`.

## Shapes

The shape vocabulary balances technical structure with refined luxury ergonomics.

### Curvature Geometry
- **Standard Cards & Data Modules:** `8px` (`rounded-md`), establishing an orderly, industrial profile that maximizes screen real estate within dense monitoring layouts.
- **Action Triggers & Inputs:** `6px` (`rounded`), providing distinct click affordance without visual softness.
- **Telemetry Chips & Port Pills:** `9999px` (`rounded-full`), reserved exclusively for persistent status indicators, port leases, and operational tags.
- **Micro Swatches:** `2px` (`rounded-xs`), utilized for multi-core oscilloscope legends and memory channel indicators.

## Components

### Buttons & Executive Triggers
- **Primary Sovereign CTA:** Solid gradient fill from `#d4a017` to `#ba9555` capped with a 1px `#ffd700` top highlight. Text is set in dense `#0c0c0e` weight 700. Hover engages an active gold aura `box-shadow: 0 0 16px rgba(240, 190, 56, 0.45)`.
- **Secondary Glass Trigger:** Translucent fill `rgba(22, 20, 20, 0.72)` with a 1px boundary of `rgba(212, 160, 23, 0.25)`. Text is `#d6d0c4`. Hover deepens border luminosity to `rgba(212, 160, 23, 0.6)`.
- **Destructive Kill Trigger:** Crimson tinted surface `rgba(239, 68, 68, 0.15)` bordered with 1px `#ef4444`. Text is `#f87171`. Used exclusively for immediate thread termination, IP blacklisting, and resource eviction.

### Data Tables & Governance Matrix
- **Headers:** Rendered in `caption` typography using bronze metadata text (`#8a8478`) with a subtle 1px bottom edge `rgba(212, 160, 23, 0.12)`.
- **Rows:** Alternating transparent states with subtle hover elevation `background: rgba(255, 255, 255, 0.02)`.
- **Technical Cells:** PIDs, memory addresses, and listening ports enforce `font-family: JetBrains Mono` with forced LTR presentation.

### Real-Time Oscilloscope Widget
- **Waveform Canvas:** 60-second sliding temporal window traversing right-to-left, rendering 8 distinct Bezier lines mapped to the multi-core diagnostic palette.
- **Telemetry Legend:** 4-column symmetric grid featuring a micro solid swatch (`■`), localized core label, mini progress track, and live usage percentage formatted to one decimal place.

### Status Badges & Port Leases
- **Active Port Lease Pills:** Elliptical capsules enclosing the port number in monospace font, companion service name, and an inline dismissal icon (`✕`).
- **Live SSE Indicator:** An emerald pulse dot (`#22c55e`) animating with an expanding ring every 1000ms to signal active telemetry intake.

### Input Fields & Search Bars
- Recessed smoked background `rgba(12, 12, 14, 0.85)` framed in 1px `rgba(212, 160, 23, 0.2)`. Focus states project an amber halo `box-shadow: 0 0 0 2px rgba(212, 160, 23, 0.3)`. Text renders in `#d6d0c4` with `#8a8478` placeholders.
