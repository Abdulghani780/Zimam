# وثيقة تصميم واجهات منظومة ASAAS Server Control
## ملف المواصفات الشامل لإنشاء التصاميم عبر Stitch (Stitch Design Specification)

> **اسم المشروع:** منظومة أساس لإدارة ومراقبة السيرفرات وحاكم الموارد والوصول المميز  
> **ASAAS Server Control & Resource Governor Enterprise v2.5**  
> **اللغة والاتجاه:** اللغة العربية بالكامل (RTL - Right To Left)  
> **الهوية البصرية:** الفخامة الرقمية السيبرانية (Cyber Dark Luxury Glassmorphism) المستوحاة من هوية أساس الثمانية (ذهب ملكي + أسود فحمي زجاجي)

### الشاشة 1: نظرة عامة ورسم بياني لأنوية المعالج (Overview & CPU Cores Oscilloscope)
> **الهدف:** شاشة المراقبة اللحظية والتحكم بالسيرفر، تتضمن الرسم البياني الزمني المتكامل للأنوية على غرار شاشات مراقبة موارد النظام في لينكس (GNOME System Monitor / Laptop view).

#### 1. بطاقات المؤشرات اللحظية (Top KPI Metric Cards):
- **بطاقة المعالج (CPU Load):** نسبة الاستهلاك الإجمالية بلحظتها (مثال: `21.8%`) مع مصغر رسم بياني Sparkline.
- **بطاقة الذاكرة (RAM Usage):** الاستهلاك الإجمالي مع تفصيل دقيق (`24.0 GB من أصل 64.0 GB` - `37.6%`).
- **بطاقة الجلسات النشطة (Active Sessions):** عدد جلسات RDP والكونسول الحالية (مثال: `3 جلسات`).
- **بطاقة التخزين (Storage C:):** النسبة المتبقية والمستخدمة (`328.7 GB متبقي من 475.8 GB`).

#### 2. الرسم البياني الزمني لمصفوفة أنوية المعالج (Multi-Core Timeline Oscilloscope Graph):
> **مواصفات دقيقة مطابقة لرسم شاشة اللابتوب (GNOME System Monitor):**
- **منطقة الرسم البياني (Canvas Viewport):**
  - خلفية سوداء شبكية مع خطوط أفقية ناعمة توضح نسب الاستهلاك: `0%`, `25%`, `50%`, `75%`, `100%`.
  - خطوط رأسية زمنية توضح مقياس آخر 60 ثانية (`60s`, `40s`, `20s`, `0s`).
  - خطوط موجية منحنية حية (Live Smooth Bezier Curves) تتحرك لحظياً من اليمين إلى اليسار مع كل تحديث SSE (كل 1 ثانية).
  - لكل نواة لون ساطع ومميز يسهل تمييزه:
    - النواة 01 (Core 1): أحمر مرجاني `#f87171`
    - النواة 02 (Core 2): برتقالي دافئ `#fb923c`
    - النواة 03 (Core 3): ذهبي أساس `#facc15`
    - النواة 04 (Core 4): أخضر زمردي `#4ade80`
    - النواة 05 (Core 5): فيروزي مائي `#2dd4bf`
    - النواة 06 (Core 6): أزرق سماوي `#38bdf8`
    - النواة 07 (Core 7): نيلي بنفسجي `#818cf8`
    - النواة 08 (Core 8): وردي قرمزي `#f472b6`
    *(مع إمكانية التمدد حتى 16 أو 32 نواة للسيرفرات الضخمة)*.
- **مصفوفة دليل الأنوية أسفل الرسم (Core Percentage Legend Matrix):**
  - شبكة مرتبة في 4 أعمدة مطابقة لصورة اللابتوب:
    - كل عنصر يتكون من: مربع لوني صغير `■` + اسم النواة (مثال: `نواة 01`) + النسبة الحالية بخط عريض (مثال: `14.2%`).
- **أشرطة التحميل المصغرة:** شريط تقدم أفقي صغير أسفل كل نواة يوضح نسبة التحميل الحالية.

#### 3. جدول جلسات المستخدمين المباشرة (Active RDP User Sessions Table):
- أعمدة الجدول:
  - معرف الجلسة (`Session #ID`)
  - اسم المستخدم والحساب (`mahmoodSaeed`, `AbdulghaniAli`, `Administrator`)
  - حالة الجلسة (`نشط - Active` بنبض أخضر أو `منفصل - Disconnected` ببرتقالي)
  - زمن الخمول (`Idle Time` بالدقائق)
  - استهلاك الذاكرة الفعلي لكل مستخدم بدقة ميغابايت (`MB` و `GB`)
  - وقت تسجيل الدخول (`Logon Time`)
  - عنوان الـ IP المتصل عبر RDP
  - **الإجراءات التفاعلية السريعة (Instant Actions):**
    - زر مشاركة الشاشة الصامتة (Stealth Shadow: تحكم كامل / مشاهدة فقط)
    - زر إرسال رسالة للشاشة (Send Desktop Message)
    - زر فصل الجلسة (Disconnect)
    - زر تسجيل الخروج الكامل (Logoff)

### الشاشة 2: مركز التحكم وحاكم الموارد الذكي (Resource Governor & System Control)
> **الهدف:** إدارة استهلاك الذاكرة والمعالج للجلسات الخاملة والخدمات المتوحشة.

#### العناصر الرئيسية:
1. **لوحة حاكم الذاكرة الذكي (Working Set Governor):**
   - مؤشر الذاكرة المستردة الإجمالي (مثال: `تم توفير 1,420 MB`).
   - خيارات السياسة التلقائية:
     - تفعيل التفريغ التلقائي للذاكرة (Auto Trim Working Set)
     - حد الخمول لتفريغ الذاكرة (بالدقائق)
     - حد الفصل التلقائي للجلسات المنسية (Auto Disconnect)
     - حد تسجيل الخروج التلقائي بعد انتهاء ساعات العمل (Auto Logoff)
   - زر إجراء فوري: "تفريغ خمول السيرفر الآن (Reclaim Inactive RAM)".
2. **جدول خدمات ويندوز الحيوية (Windows Core Services):**
   - خدمات النظام الأساسية: `TermService` (خدمة RDP), `Spooler` (الطباعة), `W32Time` (الوقت), `LanmanServer` (مشاركة الملفات).
   - عرض حالة كل خدمة (Running / Stopped / Disabled).
   - أزرار التحكم: تشغيل، إيقاف، إعادة تشغيل، وتغيير نوع البدء (تلقائي / يدوي).

---

### الشاشة 3: دليل الأصول والخوادم المدارة (Managed Server Assets & PAM)
> **الهدف:** سجل مركزي لإدارة خوادم الشركة والاتصال بها بنمط JumpServer Zero-Trust.

#### العناصر الرئيسية:
1. **شريط الأدوات:** زر "إضافة خادم جديد"، زر "فحص اتصال الكل (Scan All Ping)".
2. **بطاقات إحصائيات الأصول:** إجمالي الخوادم، الخوادم المتصلة (Online)، الخوادم غير المتصلة (Offline)، متوسط زمن الاستجابة (Latency ms).
3. **جدول الخوادم والأصول:**
   - اسم السيرفر (مع شارة "هذا السيرفر المحلي" للسيرفر المضيف)
   - العنوان والمضيف (`Host / IP Address`)
   - نوع النظام (Windows Server 2025, Ubuntu 24.04, Debian, etc.)
   - المنفذ والبروتوكول المستخدم (`3389 RDP`, `22 SSH`, `1433 MSSQL`, `443 HTTPS`)
   - الحالة اللحظية (Badge أخضر متصل / برتقالي غير متصل)
   - زمن الاستجابة (مثال: `1.2 ms`)
   - إجراءات الاتصال: زر الاتصال السريع، زر فحص الاتصال، زر حذف الأصل.

---

### الشاشة 4: خزنة الحسابات المشفرة (Encrypted Credential Vault - AES-256)
> **الهدف:** حفظ بيانات الدخول والشهادات الرقمية وكلمات سر الخوادم بأعلى معايير التشفير العسكري.

#### العناصر الرئيسية:
1. **شريط الأمان وحالة القفل:** مؤشر "الخزنة مقفلة / مفكوكة التشفير"، مؤشر القفل التلقائي بعد دقيقتين من الخمول.
2. **إضافة حساب مشفر جديد:** نافذة منبثقة لإدخال اسم الحساب، الأصل المرتبط، اسم المستخدم، كلمة السر، وملاحظات الأمان.
3. **قائمة الحسابات المشفرة:**
   - بطاقات زجاجية مشفرة تخفي كلمة المرور بنجوم `••••••••••••`.
   - زر "كشف كلمة المرور" (يتطلب إدخال الماستر كي Master Key).
   - زر نسخ اسم المستخدم وكلمة السر للحافظة بأمان مع مسحها بعد 30 ثانية.
   - شهادة التدقيق الأمني (تاريخ آخر تعديل وآخر وصول).

---

### الشاشة 5: مراقبة المنافذ ودرع العزل الذكي (Ports & Multi-Tenant Isolation Guard)
> **الهدف:** الميزة الحصرية التي طلبتها لعزل منافذ المطورين والمشاريع ومنع التداخل بين المستخدمين.

#### العناصر الرئيسية:
1. **بطاقات إحصائيات الدرع:**
   - إجمالي المنافذ المفتوحة
   - منافذ الاستماع (Listening Ports)
   - منافذ المشاريع المعزولة للمستخدمين
   - شارة "درع العزل نشط وتلقائي 100%"
2. **قسم فحص وحجز المنافذ الذكي (Autonomous Port Claim & Resolver):**
   - أزرار الفحص السريع لمنافذ التطوير الشهيرة:
     - `3000 (React / Next.js)`
     - `5173 (Vite)`
     - `8000 (Django / FastAPI)`
     - `8080 (Java / Proxy)`
     - `4321 (Astro)`
   - حقل إدخال رقم المنفذ + حقل اسم المشروع.
   - زر "فحص الحجز واقتراح بديل شاغر".
   - **بطاقة نتيجة الفحص الذكية:**
     - إذا كان المنفذ شاغراً: يظهر باللون الأخضر مع زر **"حجز هذا المنفذ حصرياً لمشروعي"**.
     - إذا كان المنفذ محجوزاً لمستخدم آخر: يظهر باللون البرتقالي محذراً باسم الزميل ورقم جلسته واسم العملية، مع اقتراح المنفذ البديل الآمن وزر **"اعتماد المنفذ البديل (مثال 3002) فوراً لمشروعي"** مع إظهار أمر التشغيل الموصى به: `PORT=3002 npm run dev`.
3. **شريط الحجوزات النشطة (Active Multi-Tenant Project Leases):**
   - شرائح (Pills) زجاجية تعرض كل منفذ محجوز ولمن يعود (مثال: `3000 - AbdulghaniAli (متجر أساس)` مع زر تحرير `✕`).
4. **جدول رادار المنافذ والشبكة (Ports Radar Table):**
   - رقم المنفذ المحلي
   - البروتوكول (TCP / UDP)
   - اسم العملية (Process Name: `node.exe`, `python.exe`, `svchost.exe`)
   - معرّف العملية (PID)
   - **المستخدم المالك وحالة العزل:** شارة توضح هل المنفذ معزول لجلسة مطور محددة أو خدمة نظام عامة.
   - خدمة ويندوز / نوع إطار العمل
   - حالة المقبس (LISTEN / ESTABLISHED)
   - العنوان البعيد المتصل
   - الإجراءات: زر إنهاء وتحرير المنفذ، زر حظر الـ IP البعيد بجدار الحماية.

### الشاشة 6: مركز الدفاع والأمان والرادار (Security Shield & Attack Radar)
> **الهدف:** رصد الهجمات ومحاولات كسر كلمات السر واعتراض الأوامر التدميرية.

#### العناصر الرئيسية:
1. **عدادات الرادار الأمني:**
   - الهجمات التي تم اعتراضها (Attacks Intercepted)
   - محاولات تسجيل الدخول الفاشلة (Failed Logons Event 4625)
   - عناوين IP المحظورة بجدار الحماية
   - شارة فحص جدار حماية ويندوز (Windows Defender Firewall Active)
2. **سجل رادار الاتصالات والمحاولات المشبوهة:**
   - جدول يعرض توقيت المحاولة، اسم المستخدم المستهدف، عنوان IP المهاجم، نوع الهجوم (Brute Force / Password Spraying).
   - زر حظر فوري للـ IP المهاجم (Block IP in Firewall).
3. **قائمة الـ IP المحظورة (Blacklist Manager):**
   - قائمة بالعناوين المحظورة مع زر فك الحظر (Unblock).
4. **محلل مخاطر الأوامر (Command Execution Risk Guard):**
   - صندوق فحص لاختبار أي أمر طرفية (CMD / PowerShell) قبل تنفيذه وتصنيفه (آمن، متوسط، خطير، تدميري).

---

### الشاشة 7: التخزين والملفات وحاويات القفل (Storage, Junk Cleaner & File Locks)
> **الهدف:** فحص سعة الأقراص، تنظيف المخلفات، وفك الملفات المحجوزة.

#### العناصر الرئيسية:
1. **بطاقة سعة القرص C:\ الأساسي:**
   - مقياس دائري أو شريط استهلاك عريض يوضح السعة الكلية، المستخدمة، والمتبقية.
   - زر "تنظيف مخلفات السيرفر وسلة المحذوفات (Clean Junk)".
2. **جدول مساحات مجلدات المستخدمين (User Profile Storage):**
   - اسم المستخدم، مسار المجلد الشخصي (`C:\Users\...`)، حجم المجلد الكلي، حجم الملفات المؤقتة (`Temp`)، وزر تنظيف ملفات المستخدم المؤقتة بنقرة واحدة.
3. **كاشف ومحرر الملفات المقفولة (Open File Locks & Unlocker):**
   - حقل بحث عن مسار أي ملف أو قاعدة بيانات لا تقبل الحذف أو التعديل.
   - كشف اسم المستخدم والعملية (Process) التي تقفل الملف مع زر "فك القفل الفوري (Force Unlock)".

---

### الشاشة 8: إدارة مستخدمي السيرفر وصلاحيات RDP (Local Users & RDP Access)
> **الهدف:** إدارة مستخدمي نظام ويندوز المحليين، التحكم بصلاحيات الدخول عن بعد، والأدوار.

#### العناصر الرئيسية:
1. **شريط الإجراءات:** زر "إضافة مستخدم ويندوز جديد"، بطاقة إجمالي المستخدمين والمستخدمين النشطين.
2. **جدول مستخدمي السيرفر (Windows Local Users Table):**
   - اسم المستخدم (`Username`)
   - الاسم الكامل والوصف
   - حالة الحساب (نشط / معطل)
   - صلاحية الوصول عن بعد (RDP Access: مسموح / غير مسموح مع مفتاح تبديل Toggle)
   - مستوى الصلاحية (Administrator كمسؤول / Standard User مستخدم قياسي)
   - عمر كلمة السر وتاريخ انتهائها
   - الإجراءات: تفعيل/تعطيل، إعادة تعيين كلمة السر، حذف المستخدم.

---

### الشاشة 9: سجل التدقيق والامتثال (Compliance Audit Trail & Logs)
> **الهدف:** سجل موثق غير قابل للتلاعب (Tamper-Proof) لجميع العمليات الحساسة بنمط أنظمة PAM المعتمدة.

#### العناصر الرئيسية:
1. **شريط أدوات الامتثال:**
   - زر تصدير السجل بصيغة JSON
   - زر تصدير السجل بصيغة CSV
   - بصمة التحقق والتشفير اللحظية (`SHA-256 Checksum`)
2. **جدول أحداث التدقيق (Audit Events Table):**
   - التوقيت الزمني الدقيق (ISO Timestamp)
   - منفذ الإجراء (المسؤول / النظام)
   - الدور والصلاحية
   - نوع الإجراء (مشاركة شاشة، تفريغ ذاكرة، تعديل مستخدم، حظر IP، حجز منفذ)
   - الهدف والمتأثر بالإجراء
   - عنوان IP الخاص بالمنفذ
   - النتيجة (نجاح / فشل)

---

### الشاشة 10: الإعدادات والإنذارات ونظام التنبيهات (Settings, Telegram & Alerts)
> **الهدف:** ضبط تنبيهات تيليجرام الآلية، إعدادات السيرفر، ومفاتيح النظام.

#### العناصر الرئيسية:
1. **بطاقة ربط بوت تيليجرام (Telegram Instant Alerts):**
   - مفتاح تفعيل تنبيهات تيليجرام (Toggle)
   - حقل إدخال رمز البوت (`Bot Token`)
   - حقل إدخال معرّف المحادثة (`Chat ID`)
   - زر "إرسال إشعار تجريبي (Test Alert)"
   - خيارات الإشعارات: تنبيه عند تجاوز المعالج 90%، تنبيه عند نقص الذاكرة، تنبيه عند هجمات كسر كلمة السر، تنبيه عند تعارض المنافذ.
2. **بطاقة معلومات النظام والجلسة:**
   - إصدار السيرفر ونواة النظام (`Windows Server 2025 Standard`)
   - رمز جلسة الكونسول المحلية (Session Token)
   - وضع التشغيل والحماية (Loopback Secure Enclave)

## 3. العناصر المشتركة والنوافذ المنبثقة (Global Modals & Overlays)

### 3.1 نافذة التنبيه الجماعي (Broadcast Modal)
- نافذة منبثقة لإرسال رسالة فورية تنبثق على شاشات كافة مستخدمي RDP المتصلين حالياً.
- تتضمن حقل عنوان الرسالة، نص الرسالة، ومدة بقاء الرسالة بالثواني مع زر إرسال ذهبي.

### 3.2 ويدجت مساعد العمليات الذكي (AI Ops Assistant Widget)
- زر أيقونة عائم في أسفل يسار الشاشة مع وهج ذهبي خفيف.
- نافذة محادثة ذكية تفاعلية باللغة العربية تجيب فورياً عن حالة المعالج، الذاكرة، المنافذ المحجوزة، وتوجيه المستخدمين لحجز المنافذ الشاغرة.

## 4. إرشادات خاصة بأداة Google Stitch لتوليد التصاميم

1. **الاهتمام الفائق بنمط الرسم البياني للأنوية (Laptop-Style Oscilloscope):**
   - يجب أن يظهر رسم الأنوية في شاشة `Overview` كشاشة رادار زمنية متعددة الألوان بدقة عالية مع شبكة خلفية مظلمة، تماماً كما في شاشة مراقبة موارد لينكس (GNOME System Monitor).
2. **دقة التفاصيل باللغة العربية (RTL):**
   - محاذاة كافة الجداول والنصوص والأيقونات من اليمين إلى اليسار.
   - الأرقام والنسب والمنافذ بخط إنجليزي واضح ومتناسق (Monospace / Sans).
3. **الحفاظ على روح الفخامة (Luxury Dark Cyber):**
   - زجاج داكن مع حدود ذهبية دقيقة، وتجنب الخلفيات الفاتحة أو الرمادية الباهتة.
